# Roadmap De Estudos

Este roadmap é flexível. Marque os itens conforme estudar e pratique em ambientes próprios, de laboratório ou explicitamente autorizados. Registre datas e evidências sem publicar informações sensíveis.

## Etapa 1 — Fundamentos
- [ ] Definir objetivos e rotina de estudo realista
- [ ] Praticar terminal e conceitos básicos de Linux
- [ ] Revisar redes: IP, DNS, DHCP, roteamento e firewall
- [ ] Aprender fundamentos de Git e documentação Markdown
- [ ] Revisar fundamentos de lógica e Python
- [ ] Estudar conceitos de banco de dados e SQL

## Etapa 2 — Infraestrutura E Virtualização
- [ ] Criar um laboratório local seguro e documentar sua arquitetura
- [ ] Estudar administração Linux e registrar exercícios em Red Hat
- [ ] Praticar conceitos de virtualização em VMware
- [ ] Explorar armazenamento em TrueNAS com dados de teste
- [ ] Documentar conceitos de backup e restauração com Veeam

## Etapa 3 — Redes, Segurança E Serviços
- [ ] Revisar fundamentos de segurança e segmentação de redes
- [ ] Realizar práticas Fortinet apenas em ambiente autorizado
- [ ] Estudar telefonia e configuração 3CX em laboratório
- [ ] Documentar controles, testes e resultados sem expor configurações privadas

## Etapa 4 — Dados E Cloud
- [ ] Criar consultas SQL com conjunto de dados fictício ou público
- [ ] Montar um relatório simples no Power BI e documentar as etapas
- [ ] Estudar fundamentos de cloud: identidade, rede, armazenamento e custos
- [ ] Desenhar uma arquitetura de estudo e registrar decisões

## Etapa 5 — Projetos E Portfólio
- [ ] Escolher um problema pequeno para resolver com um projeto
- [ ] Criar README com objetivo, tecnologias, execução e aprendizados
- [ ] Adicionar evidências sanitizadas e revisar privacidade antes de publicar
- [ ] Atualizar a página de portfólio com projetos concluídos
- [ ] Revisar o roadmap e definir o próximo ciclo de estudos
