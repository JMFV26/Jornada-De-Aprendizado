# Projetos

## Objetivo
Reúna projetos práticos que integrem os conhecimentos desenvolvidos nas trilhas de aprendizado.

## Como documentar cada projeto
Crie uma pasta por projeto e inclua um `README.md` com:
1. Problema ou objetivo
2. Tecnologias utilizadas
3. Como executar ou reproduzir
4. Imagens ou diagramas, quando úteis
5. O que aprendeu e próximos passos
