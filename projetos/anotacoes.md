# Anotações — Projetos

Use o [modelo geral de anotações](../modelo-anotacoes.md) durante o planejamento e o registro de aprendizados.

## Índice de projetos
Para cada projeto, crie uma pasta com README próprio, objetivo, tecnologias, instruções de execução, resultados e próximos passos.

## Checklist de publicação
- [ ] O projeto usa dados fictícios, públicos ou autorizados
- [ ] Segredos e informações pessoais foram removidos
- [ ] README explica como entender ou executar o projeto
- [ ] Evidências foram revisadas antes de publicar
